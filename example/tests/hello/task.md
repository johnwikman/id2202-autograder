# Hello

Implement a program that prints "Hello, World!" to standard output, then exits
with return code 0.

All code necessary to compile and run your solution shall be placed under the
directory `solutions/hello` in your source code repository. This directory must
contain a `Makefile` that builds your solution as an executable `hello`.

Example:

```bash
> cd solutions/hello
> make
> ./hello
Hello, World!
```
